# 🍽️ Scan2Serve - Restaurant QR Ordering System

## 📌 Project Overview

Scan2Serve is a full-stack Restaurant QR Ordering System that allows customers to scan a QR code placed on a table, browse the digital menu, place orders, and make payments without waiting for a waiter.

This project is being developed as a complete learning project using modern Java Full Stack technologies.
